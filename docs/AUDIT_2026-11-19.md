## Riesgos y limitaciones

- Cualquier proceso del mismo usuario puede leer el `.env`; el token no
  protege frente a malware local.
- `ALLOWED_ORIGINS=chrome-extension://*` es el valor por defecto; el token
  sigue siendo obligatorio. Al publicar se recomienda fijar el ID exacto.
- La extensión necesita acceso a todos los sitios http/https por diseño
  (selección en cualquier página); debe justificarse en la tienda.
- No se puede afirmar compatibilidad con una máquina limpia sin ejecutar
  las pruebas de instalación correspondientes.
