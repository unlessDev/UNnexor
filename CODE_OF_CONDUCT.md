# Código de conducta

## Compromiso

Este proyecto busca un entorno respetuoso, técnico y colaborativo. Se
espera un trato cordial, crítica constructiva y respeto por las diferencias
de experiencia, idioma, identidad y contexto.

## Comportamientos esperados

- Discutir ideas y código, no atacar a personas.
- Dar contexto reproducible en los reportes.
- Aceptar correcciones y reconocer errores.
- Respetar la privacidad: no publicar tokens, capturas personales ni datos
  de terceros.

## Comportamientos inaceptables

- Acoso, insultos, discriminación o amenazas.
- Publicar información privada sin permiso.
- Introducir secretos o código malicioso.
- Ignorar deliberadamente las reglas de seguridad del proyecto.

## Aplicación

El propietario del repositorio puede moderar, cerrar o eliminar
contribuciones que incumplan este código. Para reportes sensibles, usa los
canales privados de GitHub descritos en `SECURITY.md`. No se inventa un
correo de contacto.

## Alcance

Se aplica a issues, pull requests, discusiones, commits y cualquier espacio
del proyecto.
